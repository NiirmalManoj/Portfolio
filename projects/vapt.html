Executed vulnerability assessments in isolated lab environments. Utilized Nmap and Nikto for enumeration, and Burp Suite to intercept HTTP traffic.

View on GitHub

OVERVIEW

Conducted a full-scale Vulnerability Assessment and Penetration Test (VAPT) against purposely vulnerable applications like DVWA and Metasploitable. The objective was to uncover and report on critical vulnerabilities such as SQL injection, XSS, and misconfigured services.

PROBLEM STATEMENT

Applications are frequently deployed with default credentials, unpatched services, and poor input validation. Demonstrating the impact of these vulnerabilities was crucial for understanding defensive mitigation strategies.

FEATURES & FINDINGS

  • Comprehensive port scanning and service fingerprinting
  • Successful interception and manipulation of HTTP requests
  • Exploitation of broken authentication mechanisms
  • Generated detailed CVSS-scored vulnerability reports

TECHNOLOGIES USED

  • Reconnaissance: Nmap, Nikto, DirBuster
  • Web Proxy: Burp Suite Professional
  • Exploitation: Metasploit Framework, SQLmap
  • Target Env: DVWA, Metasploitable 2

LESSONS LEARNED

This project reinforced my understanding of the OWASP Top 10 vulnerabilities. I learned that automated scanning tools must be supplemented with manual validation using proxies like Burp Suite to confirm false positives and discover complex logic flaws.
