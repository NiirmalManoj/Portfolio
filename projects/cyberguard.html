CYBERGUARD SIEM & ATTACK LAB

Engineered a 3-VM cyber range to deploy a customized ELK stack and Suricata IDS. Simulated live attacks to actively triage alerts and strengthen detection.

View on GitHub Live Demo

OVERVIEW

The Cyberguard SIEM & Attack Lab is a comprehensive, isolated environment designed to simulate real-world cyber threats and effectively monitor them. By integrating an ELK stack and Suricata, I was able to correlate logs, identify malicious behaviors, and establish a robust baseline for threat detection.

PROBLEM STATEMENT

Modern enterprise environments lack visibility into advanced persistent threats. The challenge was to create a low-cost, high-efficiency detection pipeline that could ingest diverse log sources and automatically flag suspicious activities in real-time.

FEATURES

  • Real-time log ingestion and parsing via Logstash
  • Intrusion Detection utilizing Suricata signatures
  • Custom Kibana dashboards for threat visualization
  • Automated alerting based on specific IOC thresholds

TECHNOLOGIES USED

  • Infrastructure: VirtualBox, Docker
  • SIEM: Elasticsearch, Logstash, Kibana (ELK)
  • Detection: Suricata IDS, Zeek
  • OS: Ubuntu Server, Kali Linux

IMPLEMENTATION & CHALLENGES

The implementation involved setting up 3 VMs: a victim machine, an attacker machine, and a centralized SIEM server. Configuring Logstash to correctly parse complex Suricata JSON logs required extensive Regex tuning.

Challenge: Resource constraints when running the full ELK stack alongside multiple VMs.
Solution: Optimized JVM heap sizes and utilized lightweight Docker containers for the ELK components to minimize overhead.

LESSONS LEARNED & FUTURE IMPROVEMENTS

I gained deep insights into the lifecycle of an attack and how different phases manifest in system logs. In the future, I plan to integrate a SOAR (Security Orchestration, Automation, and Response) platform to automate the initial triage and response actions.
